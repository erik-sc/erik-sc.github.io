# erik-sc.github.io

Portfolio pessoal de Érik Schünemann. Site estático (HTML, CSS e JavaScript, sem build).

- `ascii.js`: campo de ondas em ASCII do topo, com a superfície de água que reage ao cursor.
- `sections.js`: entrada das seções ao rolar e os glifos animados dos títulos.

Para ver localmente:

```bash
node serve.mjs 4321
```
